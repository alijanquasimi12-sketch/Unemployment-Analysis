# Unemployment Analysis

This project provides an interactive dashboard and data analysis engine for exploring unemployment trends in India. It includes an AI-driven simulation tool and comprehensive exploratory data analysis (EDA) to help understand economic patterns and the impact of events like the COVID-19 pandemic on employment.

## Features
- **Interactive Dashboard:** View comprehensive statistics, plots, and insights on unemployment data.
- **Data Processing Engine:** Robust data cleaning and processing using Pandas and NumPy.
- **Dynamic Visualizations:** Interactive charts and graphs generated with Plotly.
- **AI Simulations:** Run simulated scenarios adjusting the unemployment rate, employed population, and labor participation rate.
- **Policy Recommendations:** Actionable data-driven recommendations and AI executive insights.
- **State Rankings & Command Center:** Detailed breakdown of unemployment metrics across different states.

## Technologies Used
- **Backend:** Python, Flask, Werkzeug
- **Data Science & Analysis:** Pandas, NumPy
- **Data Visualization:** Plotly
- **Frontend:** HTML, CSS, JavaScript

## Installation and Setup

1. **Ensure Python is installed** on your system.
2. **Navigate to the project directory** in your terminal.
3. **Install the required dependencies:**
   ```bash
   pip install -r requirements.txt
   ```
4. **Run the Flask application:**
   ```bash
   python app.py
   ```
5. **Access the Application:** Open your web browser and navigate to `http://127.0.0.1:5001`

## Usage
- Upon launching, the application can use a default dataset (`Unemployment in India.csv`) or you can upload your own relevant CSV dataset through the interface.
- Use the web interface to clean the data and generate dashboard metrics.
- Navigate through different sections of the application to view the Exploratory Data Analysis, COVID-19 impact, Early Warnings, and Policy Labs.
